\section*{Abstract} 
The aim of this master's thesis is to design and partially implement an original 2.5D RPG video game set in a fantasy world inhabited by anthropomorphic animals. The player takes on the role of a Bat Thief who accidentally discovers a mysterious book written in a long-lost human language. The game's narrative revolves around exploration, puzzle-solving, and uncovering the secrets of a forgotten past, with a key gameplay mechanic based on dice rolls that influence interactions with the environment.

This project encompasses a complete creative process — from narrative development and character design to stylized 2D artwork and the implementation of core mechanics using the Godot game engine with C\# in Visual Studio Code. 2D graphics were created in Clip Studio Paint, while Blender is planned for the development of 3D assets and animations. Music and sound effects are intended to be produced in FL Studio.

The work takes an interdisciplinary approach, combining technical, artistic, and narrative elements. It focuses not only on the practical use of modern game development tools but also on the creative process of building a coherent game world and memorable characters. The final result is a functional game prototype that may serve as a foundation for further development or as an example of an independent, author-driven game production.
